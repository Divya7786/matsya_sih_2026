# MATSUYA_AI_SIH

**MATSUYA AI (SIH26176)**: Intelligent Marine Analytics, Multi-Spectral Satellite Oceanography & Voice-First Ocean Decision Support Cockpit.

## Features
- **Global 3D Ocean GIS**: Real-time layer rendering for SST, Salinity, Current Velocities, Chlorophyll-a, and Sea Ice.
- **Potential Fishing Zone (PFZ) Advisory**: Multi-spectral thermal and ocean color front triangulation for fuel-efficient fishing routes.
- **MATSUYA Voice AI Assistant**: Multimodal reasoning engine for marine weather advisories, sea-state warnings, and vessel guidance.
- **Coastal Hazards & Safety**: Cyclonic storm tracking, high-wave swell alerts, and localized marine weather alerts.
